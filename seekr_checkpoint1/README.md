# seekr_checkpoint1
📌 Project Overview

Seekr AI is an AI-powered search and chat application built using Flutter and Firebase.
It allows users to sign up, log in, recover passwords, and access a chat interface, along with history and profile pages, all inside a clean and spooky-themed UI.

The app focuses on authentication, navigation, and user experience, forming the foundation for a full AI-based assistant.

🎯 Features Implemented
🔐 Authentication (Firebase)

Email & Password Login

User Registration (Sign Up)

Forgot Password (Password Reset Email)

Secure Logout

🧭 Navigation

Smooth navigation after login

Bottom navigation with:

💬 Chat Page

🕓 History Page

👤 Profile Page

🎃 UI & Theme

Dark Halloween-style theme

Gradient buttons and inputs

Clean and user-friendly layout

Consistent design across all screens
